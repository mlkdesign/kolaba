# kolaba — прототип в мокапе iPhone

Демо-страница: приложение kolaba отрисовано внутри картинки iPhone. Код общий
с мобильной веб-версией **kolaba-web** (https://mlkdesign.github.io/kolaba-web/) —
папки `css/` и `js/` в двух проектах побайтово одинаковые, различаются только
оболочка (`index.html`) и один файл стилей режима мокапа.

## Запуск

```bash
python3 -m http.server 8000
```

и открыть http://localhost:8000/ — модули (`<script type="module">`) требуют
`http://`, по `file://` браузер их заблокирует.

## Чем отличается от веб-версии

Единственная принципиальная разница — **кто скроллит длинные экраны**.

В вебе это сам документ: Safari сворачивает свою нижнюю панель только когда
двигается корневой скроллер. Внутри мокапа документ скроллиться не может —
приложение лежит в коробке фиксированного размера, а шапки и нижнее меню не
могут быть `position: fixed`, иначе они привязались бы к окну браузера, а не к
экрану телефона. Поэтому в мокапе скроллером снова становится контейнер контента
внутри экрана.

Режим включает класс `is-mockup` на `<html>`:

- `css/mockup.css` (подключается последним) возвращает контейнерам
  `position: absolute; overflow-y: auto`, а оконным слоям — `position: absolute`;
- `js/ui/page-scroll.js` спрашивает позицию прокрутки у нужного элемента:
  у документа в вебе и у активного контейнера в мокапе;
- роль системной строки играет фейковый статус-бар — он занимает верхние 33px
  холста, ровно столько же в вебе даёт `env(safe-area-inset-top)`, поэтому все
  отступы считаются одной и той же формулой.

Разметка экранов одна и та же: секции `data-screen` в обоих проектах совпадают,
отличается только обвязка вокруг `#app`. Приложение больше не масштабируется
трансформом из координат 402×874 — оно тянется по фактической ширине экрана.

`css/mockup.css` лежит и в kolaba-web — не подключён, но оставлен, чтобы `css/`
и `js/` можно было копировать между проектами целиком, без исключений.

## Экраны и хеш-адреса

| Адрес                   | Экран                                                        |
| ----------------------- | ------------------------------------------------------------ |
| `#start`                | Стартовый экран: стена фотографий, свечение                   |
| `#auth`                 | Sign Up / Log In, показать пароль                             |
| `#setup1`               | Регистрация, шаг 1: имя, гражданство, местоположение          |
| `#setup2`               | Регистрация, шаг 2: фотографии, описание, соцсети             |
| `#profile`              | Профиль: вкладки Video / Photos, сетка, просмотрщик фотографий |
| `#profileReels`         | Ролики профиля                                                |
| `#feed`                 | Лента видео                                                   |
| `#projects`             | Проекты: три вкладки, карточки, закладки, экран проекта       |
| `#notifications`        | Уведомления                                                   |
| `#notificationClip`     | Ролик, открытый из уведомления                                |
| `#notificationProject`  | Проект, открытый из уведомления                               |
| `#messages`             | Мессенджер: список чатов и переписка                          |
| `#settings`             | Настройки                                                     |

Каждый экран — отдельная запись в history, поэтому кнопки «назад» и «вперёд»
в браузере ходят по экранам приложения. Кнопка «Go to Main page» под телефоном
возвращает на Start Page.

## Структура

```
index.html          мокап телефона и разметка экранов внутри #app
css/
  base.css          токены, сброс, шрифты, кнопки, поля, нижнее меню
  start.css …       по файлу на экран
  layers.css        слои, привязанные к окну
  mockup.css        режим мокапа (подключается последним)
js/
  app.js            точка входа: порядок загрузки модулей и старт
  core/router.js    экраны, history, хеш-адреса
  core/state.js     состояние, общее для нескольких экранов
  data/             каталоги фотографий и видео
  ui/               шторка выбора, просмотрщик фото, видео, клавиатура,
                    размеры окна, смахивание для закрытия, выбор скроллера
  screens/          по модулю на экран
assets/
  iphone.png        рамка мокапа (экран внутри прозрачный)
  fonts/            Geist в woff2
  icons/            иконки интерфейса, включая фейковый статус-бар
  data/authors.json офлайн-фолбэк для аватарок
```

## Что интерактивно

- переходы между всеми экранами, кнопка Back, история браузера;
- переключатель Sign Up / Log In, показать пароль;
- загрузка и удаление до 10 изображений профиля, счётчик символов в описании;
- имя, ник и описание из формы подставляются в профиль;
- вкладки Video / Photos и вкладки Projects — нативное листание со прилипанием,
  розовая полоска едет за страницей;
- Projects: вымышленные заказы, поиск, закладки, pull-to-refresh, экран проекта
  с заявками, пейволл kolaba.pro;
- вертикальная лента видео и горизонтальное листание роликов автора; долгое
  нажатие ставит ролик на паузу;
- фотографии профиля и вложения проектов закрываются смахиванием вверх или вниз;
- мессенджер: 20 чатов, переписка, ответы-заглушки;
- настройки: все секции, переключатели, подэкраны — изменения видны в профиле.

Видео: `muted`, `playsinline`, с постерами; играет только видимый ролик,
одновременно «живыми» держатся не больше трёх элементов `video`, файлы тянутся
с Pexels в 1080p.
