# kolaba — HTML-прототип

Статичная страница с интерактивным прототипом приложения внутри мокапа iPhone.
Никакой сборки не нужно: открой `index.html` в браузере (или залей папку на любой хостинг).

## Экраны

| Экран | Как попасть |
|---|---|
| Start Page | стартовый |
| Sign Up / Log In | кнопка «Let's collabs for free» или `index.html#auth` |
| Профиль, шаг 1 | «Next step» или `#setup1` |
| Профиль, шаг 2 | «Next step» или `#setup2` |
| Projects | первый пункт нижнего меню или `#projects` |
| Видеолента | центральный пункт нижнего меню или `#feed` |
| Мой профиль | «Skip» / «Let's collabs» или `#profile` |

Кнопка «Go to Main page» под телефоном всегда возвращает на Start Page.

## Что интерактивно

- переходы между всеми экранами, кнопка Back;
- переключатель Sign Up / Log In — розовая капсула переезжает, подписи у Google/Apple меняются;
- показать/скрыть пароль;
- загрузка и удаление до 10 изображений профиля, счётчик символов в описании;
- имя, ник и описание из формы подставляются в профиль;
- вкладки Video / Photos: тап и горизонтальный свайп, розовая полоска едет за страницей;
- Projects: вымышленные заказы, поиск, вкладки, сохранение и pull-to-refresh;
- вертикальная видеолента и горизонтальное листание роликов одного профиля;
- бесконечная лента фотографий на Start Page и переливающееся свечение — как в приложении.

## Структура

```
index.html      разметка всех экранов
styles.css      стили, токены (розовый #FF0077, чёрный фон, Geist)
app.js          переходы, переключатели, сетка контента
assets/
  iphone.png    мокап телефона (экран внутри прозрачный)
  logo.svg      логотип
  photos/       фотографии для ленты и сетки профиля
  icons/        иконки из проекта
  fonts/        Geist (Regular, Medium, SemiBold, Bold, ExtraBold)
```

Приложение свёрстано в координатах экрана iPhone (402×874) и масштабируется
под размер мокапа — пропорции совпадают с реальным приложением.
