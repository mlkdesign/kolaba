# Перенос SwiftUI → Web (сделано в WEB MVP 01)

1. Бэкенд на Cloudflare (Worker + D1, R2-ready) повторяет модель `kolaba-app/backend` (Supabase-проект): аккаунт → профили (1 creator + ≤5 business), всё привязано к profile_id, правила на сервере.
2. Веб-клиент: Vite + TypeScript + Preact (3 КБ рантайм, компоненты как во SwiftUI, без UI-китов). Навигация: 5 табов, у каждого свой стек экранов; нижние экраны остаются смонтированными → позиция прокрутки и данные сохраняются; горизонтального свайпа между табами нет.
3. Визуал — токены `KolabaColors`/`KolabaTypography`, иконки и шрифты iOS, стеклянный таб-бар-капсула 358×60, шиты внутри экрана устройства, свечения профиля, бизнес-акцент синий.
4. Realtime — адаптивный polling `/v1/sync` (15 с; 4 с в открытом чате; пауза в фоне) — укладывается в Free без Durable Objects.
5. Следующие шаги: R2 (загрузки), Resend (регистрация), затем копирование демо-видео в R2, Durable Objects для мгновенного чата, OAuth.
