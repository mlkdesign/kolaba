# Ограничения WEB MVP 01

- **R2 не включён** → загрузка медиа (аватары, портфолио, видео, вложения в чат) отвечает 503. Код загрузки потоком в R2, Range и подписанные ссылки готовы, но не проверены вживую.
- **Нет ключа Resend** → регистрация закрыта (`registration_closed`), сброс пароля не отправляет письма. Работают 4 демо-аккаунта.
- Демо-видео отдаются напрямую с CDN Mixkit/Pexels (лицензии разрешают использование; hotlinking явно не оговорён). После включения R2 их стоит скопировать в `kolaba-media` (та же модель media, меняется provider).
- Аватары бизнесов и креаторов без видео — монограммы (не стоковые лица); аватар креатора = кадр его первого видео.
- Realtime — polling (до 4 с задержки в открытом чате, 15 с для счётчиков), не WebSocket.
- Транскодинга нет: загружаемые видео должны быть MP4/MOV, совместимые с браузером.
- Блокировка пользователей — только через admin API (роль admin назначается в D1 вручную), без UI админки.
- Figma не открывалась: визуал перенесён по iOS-коду; точное попиксельное сравнение не проводилось.
- Ветки `Colaba` не существует — работа сделана в `mlkdesign/kolaba` (`main`).
